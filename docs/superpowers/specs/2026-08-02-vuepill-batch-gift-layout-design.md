# Vue-魔丸批量赠送与资源区布局设计

## 目标

- 删除兑换魔力区域的保留数量提示和功能说明，只保留数据、数量输入和兑换按钮。
- 物品栏与炼造工坊分别占据一整行，并延续当前 Vue-农场风格的主题自适应卡片。
- 在保留单件赠送的同时增加安全的批量赠送入口。

## 页面设计

物品栏标题右侧放置“批量赠送”和“赠送统计”两个按钮。批量赠送弹窗共用一个接收方 UID，列出当前可赠送物品；用户勾选多个物品后，为每项填写数量。默认不勾选任何物品，避免误送。提交前显示第二次确认摘要。

资源区域改成单列外层布局。物品栏全宽后使用自动填充的多列物品卡片；炼造工坊位于下一行，全宽显示两列配方。宽度小于 900px 时配方改为单列，宽度小于 600px 时标题按钮和弹窗内容允许换行，保持无横向滚动。

## 后端设计

新增 `POST /plugin/VuePill/gift-items`。请求包含一个 `target_uid` 和一个 `items` 数组，每项包含 `item_name` 与 `quantity`。

后端先完成全部输入和库存校验，包括：普通字典和列表、1 至 20 种不重复物品、正整数数量、单项最多 500、物品存在且当前可赠送、数量不超过库存。预检失败时不发送任何赠送请求。

预检通过后按列表顺序调用网站已有的单件赠送动作，并继续保持不可逆操作不自动重试。全部成功后只刷新一次状态并写入一条合并历史。中途失败时立即停止，返回已经成功的项目和失败项目，并刷新状态；前端关闭旧弹窗，避免用户重复提交已经成功的部分。

## 错误处理

- 全部校验错误：返回失败，不产生赠送记录。
- 第一项请求失败：返回普通失败，弹窗保留供用户修改。
- 部分成功：返回 `partial: true`、成功项目和失败项目，前端显示警告并关闭弹窗。
- 赠送成功但最终刷新失败：赠送仍算成功，消息提醒用户稍后手动刷新。

## 测试

- 后端测试覆盖请求校验、重复物品、库存不足、全部成功、首项失败和部分成功停止。
- 前端契约测试覆盖全宽布局、说明文字移除、批量按钮、弹窗、二次确认和 `/gift-items` 请求。
- 运行 Vue-魔丸全部测试、Python 编译、前端构建与发布文件一致性检查。
- 在 MoviePilot 中验证桌面和手机宽度、浅色和深色主题，以及批量赠送弹窗；真实赠送只使用最小数量测试。
