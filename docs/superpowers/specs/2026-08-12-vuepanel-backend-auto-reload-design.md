# Vue-面板后端自动切换设计

## 背景

Vue-面板从插件市场更新后，前端文件已经是新版本，但插件接口偶尔仍绑定旧的后端实例。此时市场和页面会显示新版本，`/plugin/VuePanel/status` 返回的 `dashboard.schema_version` 却还是旧版本。

根因是 PluginManagerVue 当前只调用 `PluginManager().reload_plugin()` 和 `Scheduler().update_plugin_job()`。这会重建插件实例和定时任务，但不会重新注册 FastAPI 插件接口。MoviePilot 自带的 `/plugin/reload/{plugin_id}` 接口还会调用 `register_plugin()`，因此只有走 MoviePilot 自带重载流程，接口才会绑定到新版实例。

「重置插件」虽然也能触发完整重载，但会先删除配置和插件数据，导致用户必须重新导入，还可能因运行时间丢失而错误补跑当天任务。

## 目标

- 更新 Vue-面板后自动切换到新版后端，不再要求重置插件。
- 保留全部卡片、Cookie、Cron、运行时间和日志。
- 防止重复重载或形成请求循环。
- 自动重载失败时提供清晰的手动恢复入口。

## 方案

### 构建版本

Vite 构建时从 `package.json` 读取版本号，并通过编译常量写入前端产物。前端不手写另一份版本号，避免发布时漏改。

后端继续通过状态接口中的 `dashboard.schema_version` 返回实际运行版本。

### 版本判断

页面首次读取状态后比较前后端版本：

- 版本一致：正常加载，不执行额外操作。
- 前端版本较新：说明新版前端已下载，但后端接口仍绑定旧实例，进入自动重载。
- 后端版本较新：说明浏览器仍缓存旧前端，不重载后端，只提示重新打开页面。
- 后端版本缺失或格式异常：按旧后端处理，但本次会话只尝试自动重载一次。

版本比较放入独立工具函数，支持 `0.1.37`、`v0.1.37` 等现有格式。

### 自动重载

自动重载调用 MoviePilot 自带接口：

```text
GET /plugin/reload/VuePanel
```

该接口会依次完成：

1. 停止旧插件实例。
2. 清除 Python 模块缓存并加载新版代码。
3. 恢复原有插件配置。
4. 重新注册定时任务、命令和插件 API。

此流程不调用 reset，也不删除配置或插件数据。

重载返回成功后，前端短暂等待并重新读取状态。只有状态接口返回的后端版本与前端版本一致，才视为切换成功。

### 循环保护

前端使用 `sessionStorage` 记录当前前端版本的自动重载尝试。同一浏览器标签页、同一前端版本最多自动尝试一次。

状态重新读取仍不一致时，不再自动调用接口，避免无限重载。页面显示版本不一致提示和「重新加载后端」按钮，用户可以手动重试。

### 页面提示

正常情况下不新增提示，不影响现有状态页。

只有版本异常时显示紧凑提示：

- 自动切换中：显示「正在切换到新版后端」。
- 自动切换成功：重新加载状态并显示短暂成功消息。
- 自动切换失败：显示前端版本、后端版本和「重新加载后端」按钮。
- 后端比前端新：提示关闭并重新打开 Vue-面板，以加载新前端文件。

## 错误处理

- MoviePilot 内置重载接口无权限或请求失败时，保留当前页面和配置，不调用重置。
- 重载接口成功但状态版本仍旧时，按失败处理并停止自动尝试。
- 重载过程中状态请求短暂失败时，按固定次数重试；超过次数后显示手动按钮。
- 手动重载仍失败时，展示原始错误信息，方便继续排查。

## 测试

### 单元测试

- 前后端版本一致时不重载。
- `0.1.38` 前端遇到 `0.1.37` 后端时需要重载。
- 后端版本比前端新时不重载。
- 带 `v` 前缀的版本可以正确比较。
- 缺失或异常后端版本只触发一次恢复尝试。
- 已写入会话标记时不再次自动重载。

### 前端流程测试

- 首次状态响应为旧版本时调用 `/plugin/reload/VuePanel`。
- 重载后状态变为当前版本时恢复正常页面。
- 重载失败时显示手动按钮。
- 手动重载可以再次发起请求。

### 实机验证

从旧版后端更新到新版前端后直接打开状态页，确认后端版本自动切换，且卡片、Cookie、Cron、日志和 `last_run` 均保持不变。

## 发布

- Vue-面板版本升级到 `v0.1.38`。
- 更新 `plugin_version`、`package.json` 和市场文件中的版本与历史说明。
- 重新构建 Vue 前端产物。
- 通过自动化测试、Python 语法检查和前端构建后提交并推送到 `main`。

## 不在本次范围

- 不修改 MoviePilot 核心源码。
- 不依赖 PluginManagerVue 才能完成版本切换。
- 不改变现有卡片配置格式和运行规则。
- 不自动重置插件，也不自动导入或覆盖配置。
