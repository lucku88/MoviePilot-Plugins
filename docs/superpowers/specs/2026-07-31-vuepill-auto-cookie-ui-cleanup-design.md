# Vue-魔丸自动 Cookie 与页面精简设计

## 1. 目标

- 配置页打开时自动读取 MoviePilot 中 `si-qi.xyz` 的最新 Cookie，并填入 Cookie 输入框。
- Cookie 默认以圆点隐藏，点击眼睛按钮后显示真实内容，交互和 `Vue-思齐农场 v1.0.3` 一致。
- 未编辑自动填入的 Cookie 时，保存配置不得把它固化为手动 Cookie；后续请求继续从 MoviePilot 自动同步最新值。
- 用户手动修改 Cookie 后保存为手动值；清空后恢复 MoviePilot 自动同步。
- 炼造卡片不显示“炼造上限为 0”或“材料不足”的重复提示。
- 状态页顶部移除“执行”按钮，仅保留“刷新、配置、关闭”。

## 2. Cookie 数据流

后端继续分开保存“手动 Cookie”和“当前实际使用的 Cookie”。配置 GET 接口在没有手动 Cookie 时即时读取 MoviePilot 站点 Cookie，只把读取结果返回给当前配置页面，不写入插件持久化配置。

前端记录 Cookie 是否由后端自动填入，以及用户是否编辑过输入框。保存时：

1. 自动填入且未编辑：提交空字符串，后端保持自动同步。
2. 用户填写新内容：提交该内容，后端保存为手动 Cookie。
3. 用户清空输入框：提交空字符串，后端恢复自动同步。

状态接口、日志、执行历史和通知不得包含 Cookie。

## 3. 页面行为

- Cookie 使用现有自适应主题的 `v-textarea`，默认添加隐藏样式，眼睛按钮保留清晰的无障碍名称。
- 配方可炼造数量大于 0 时仍显示“最多 N”；数量为 0 时不显示该行信息。
- 因材料不足导致不可炼造时不显示红色原因条；其他明确的“不支持”或异常状态仍可显示。
- 移除顶部“执行”按钮及前端无调用入口的 `runNow` 方法，后端 `/run` 接口和配置页“立即运行一次”开关保持不变。
