# Vue-玩偶 v0.2.0 完整升级设计

## 目标

将 Vue-玩偶升级到 `v0.2.0`，使状态页和配置页与当前 Vue-农场、Vue-魔丸保持同一套思齐农场自适应风格，并修复外展请求过密、自己展位保护缺失、IPv4 全局限制、展柜统计错误和热更新旧接口问题。升级必须保留现有配置、执行历史、Cookie 和动态调度计划。

## 自动执行顺序

每轮自动任务固定按以下顺序执行：

1. 收回已经完成的自己展位玩偶。
2. 收回已经完成的外展玩偶。
3. 使用当前可用玩偶补满自己展位。
4. 检查自己展位保护时间。
5. 未触发保护时，才使用剩余玩偶寻找他人空展位。

自己展位永远优先于外展。外展动作不得占用本轮可用于补自己展位的玩偶。

## 自己展位保护

配置页新增“自家展位保护时间”，单位为小时，默认 `1` 小时，可设置为 `0` 关闭。

当同时满足以下条件时暂停外展：

- 自动收回和自动展出均已开启。
- 柜子里已有可用玩偶。
- 自己展位中最近一只自己的玩偶距离可收回时间小于或等于保护时间。

保护生效后，本轮不再寻找他人展位，下一次动态任务直接跟随自己展位的最近可收回时间。到点后先收回并补满自己家；自己家重新补满后，如仍有剩余玩偶，才恢复外展。

## 外展限速

- 每轮最多随机检查 3 个外展目标，不再无视配置固定尝试至少 24 次。
- 本轮没有找到空位时，最早 10 分钟后再尝试，不再每 45 秒重复运行。
- 一次网络请求最多尝试 5 次。关闭 `urllib3` 的底层重复重试，避免与插件重试叠加成最多 25 次。
- 连续执行异常仍沿用现有最多 5 轮短间隔补跑限制。

## Cookie 与网络

- 插件启动、保存配置和执行前优先从 MoviePilot 的 `si-qi.xyz` 站点配置同步 Cookie。
- 配置页保留可隐藏、可显示的 Cookie 输入框，站点同步失败时使用已保存 Cookie 作为备用。
- 移除“自动同步 Cookie”开关，默认始终自动同步。
- 移除“强制 IPv4”设置和全局网络补丁，由系统自动选择可用的 IPv4 或 IPv6。

## 热更新兼容

所有 Vue API 路由在收到请求时检查 MoviePilot 当前运行的 Vue-玩偶实例。若市场更新后旧路由仍然存在，请求自动转交给新版实例，避免页面显示旧版本、保存到旧配置或刷新提示插件正在停止。

## 状态页

状态页直接使用 Vue-农场、Vue-魔丸现有的思齐农场风格：

- 顶部为图标、插件名和“刷新 / 执行 / 配置 / 关闭”紧凑按钮组。
- 四张概览卡显示当前魔力、累计曝光、累计收获魔力和自己展位占用，例如 `3/3`，不再错误显示 `0`。
- 动态任务卡显示最近自己收回、最近外展收回、下次运行和当前自家保护状态。
- 自己展位放在玩偶柜和外展操作之前，突出“先保自己家”的使用顺序。
- 保留盲盒商店、我的盲盒、玩偶柜、自己展位、指定或随机找外展位、外展记录、网站活动记录和执行历史。
- 执行历史继续使用单行摘要，时间靠右。
- 使用 MoviePilot 主题变量和 Vuetify 组件自动适配浅色、深色及其他主题，不再自行检测主题或写死整页深色背景。
- 手机端改为单列或紧凑双列，按钮可触摸区域不小于 44 像素，不产生横向滚动。

## 配置页

配置页使用与 Vue-农场相同的顶栏、卡片、开关和参数输入样式：

- 基础设置：启用插件、开启通知、使用代理、立即运行一次。
- 自动化策略：自动收回、自动展出。
- 参数设置：自家展位保护时间、随机延迟。
- Cookie：默认站点同步、密码样式隐藏、可点击显示；保留手动备用值和立即同步按钮。

不再显示“自动同步 Cookie”和“强制 IPv4”开关。旧配置中的这两个字段会被安全忽略，不影响其他配置迁移。
