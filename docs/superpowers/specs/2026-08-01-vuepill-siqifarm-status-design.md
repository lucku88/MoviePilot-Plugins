# Vue-魔丸状态页思齐农场风格移植设计

## 目标

将 Vue-魔丸状态页调整为 Vue-思齐农场 v1.0.3 的同套界面风格，同时修正配置页“保留魔丸”和“随机延迟”输入值视觉偏上的问题。只调整前端展示，不改变搬砖、沙滩、炼造、兑换和动态调度的后端行为。

## 设计原则

- 直接复用 Vue-思齐农场状态页的卡片结构、间距、圆角、边框、阴影和主题变量，不再为魔丸另外设计一套视觉语言。
- 保持 MoviePilot 浅色、深色及其他主题自动适配，不写死整页背景色。
- 功能名称、数值和操作仍使用 Vue-魔丸数据；不复制 Vue-思齐农场的农场业务逻辑。
- 页面只向用户展示业务状态，不展示“后端标记可执行”“后端标记不可执行”等开发用语。
- 不新增设置项，不改变现有已保存配置。

## 状态页结构

### 顶部概览

沿用 Vue-思齐农场的概览卡片布局和响应式列宽，显示 Vue-魔丸已有核心数据。卡片使用统一中性表面，颜色只用于图标和少量状态强调，不使用整块高饱和背景。

### 搬砖与沙滩

搬砖、沙滩使用 Vue-思齐农场相同的普通信息卡结构：标题和图标位于卡片头部，当前状态作为副标题或小型状态标签，详细数值位于下方紧凑信息区，操作按钮沿用参考插件的位置和尺寸。

搬砖状态文案：

- 可执行：`可以搬砖`
- 当日额度已满：`今日已完成`
- 无可搬砖块：`暂无砖块`
- 尚未取得状态：`等待刷新`

沙滩状态文案：

- 有垃圾或可执行：`可以清理`
- 冷却尚未结束：`冷却中`
- 尚未取得状态：`等待刷新`

后端提供的 `status_text` 继续作为说明文字使用，例如“今日搬砖已满”“沙滩冷却中”。状态文案和说明文字不得表达相互矛盾的信息。

### 炼造、兑换与执行历史

炼造、兑换、下次运行和执行历史全部套用 Vue-思齐农场对应区块的卡片标题、内容间距和列表风格。保留 Vue-魔丸已有字段、按钮权限、加载状态、空状态和错误提示。

### 响应式行为

- 桌面端使用参考插件的多列布局。
- 窄屏自动改为单列，卡片内容不可横向溢出。
- 状态标签、数值和按钮在小屏可以换行，但不能互相覆盖。
- 保持按钮触控区域和文字可读性。

## 配置页输入对齐

“保留魔丸”和“随机延迟”继续使用现有 Vuetify 浮动标签输入框。统一输入区域、前置图标和数值的垂直中心线，不改变字段高度、标签位置、提示文字或校验逻辑。相同数字输入框应共享规则，避免只修两个字段后其他参数仍不一致。

## 数据与行为边界

- 不改 Vue-魔丸 API。
- 不改搬砖和沙滩的 `ready`、`has_trash`、冷却时间等判断。
- 不改立即操作按钮的禁用条件。
- 不改插件保存、初始化刷新、补跑、重试和通知逻辑。
- 页面缺少数据时显示友好的等待状态，不伪造可执行状态。

## 发布与兼容

- 作为小版本更新发布，保留用户现有配置。
- 同步后端插件版本、前端 `package.json`、`package-lock.json`、市场索引和 README 更新说明。
- 重新构建 Vue 前端 `dist`，确保 MoviePilot 安装后直接显示新页面。

## 验证

- 对照 Vue-思齐农场状态页检查卡片结构、间距、主题适配和移动端布局。
- 检查搬砖已完成、搬砖可执行、沙滩冷却、沙滩可清理、等待刷新五类状态文案。
- 检查按钮禁用和加载状态未发生行为变化。
- 检查“保留魔丸”和“随机延迟”在浅色、深色主题中垂直居中。
- 运行前端构建、后端编译、现有 Vue-魔丸测试及 `git diff --check`。
